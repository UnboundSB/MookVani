# Directory Structure: Backend/training

Model training and evaluation scripts for word-level and sentence-level sign recognition.

All the word-level trainers share the **same data selection rule** (implemented in
`Backend/utils/dataloader_word.py`): only the top-most frequent classes of the word
corpus are loaded — a class with fewer than **14** clips is eliminated from the loader
(its files stay on disk, the pretrainer still uses them) and every surviving class
contributes at most **20** clips. The resulting vocabulary is **228 classes / 3941
clips** (a spread of 1.43x, against 5.5x on the raw corpus) and it is published in
`Backend/models/word_vocabulary/classes.json`.

All of them also read the **canonical split manifest**
(`Backend/models/word_vocabulary/split.json`), so a clip that is training data in one
phase is never validation data in another — `python scripts/audit_split_leakage.py`
proves it (fingerprint `76586776f574e698`, 3135 train / 806 val clips, 0 overlap).

All the geometric/temporal augmentations live in `Backend/utils/pose_augmentation.py`
(mirror around the signer's own axis, tilt around the neck, bounded left/right shift,
speed up / slow down, temporal shift, SpecAugment, temporal hole filling).

## Files
- Every phase trainer now ALSO writes the **standard report** (`utils/plotting.py`): the loss, the accuracy, the F1/precision/recall, the WER, the learning rate, the confusion matrix with its readable text report and the per-class metrics, all prefixed with `standard_` so they do not collide with the phase-specific figures. They also save `predictions.json` (the validation (true, predicted) pairs), without which the confusion matrix cannot be drawn.
- `common_cli.py`: The **shared CLI** of the word-level phase trainers (`--epochs`, `--batch_size`, `--num_workers`, `--data_dir`, `--out_dir`). The phase trainers used to ignore `sys.argv` completely — `python phase4_trainer.py --epochs 1` silently ran the full 50 epochs — and their DataLoader was pinned to `num_workers=0`, which left the whole augmentation on a single core. Now the workers load **and** augment the clips in parallel (2-3 cores), and `--out_dir` lets a short benchmark run write somewhere else than the real checkpoints.
- `evaluate_reconformer.py`: Generic evaluation script for ReConformer model architectures.
- `evaluate_synthetic_sentences.py`: Calculates Word Error Rate (WER) and loss metrics on synthetic sentence data.
- `generate_training_plot.py`: Visualizes training and validation curves from metric histories.
- `phase2_trainer.py`: Phase 2 fine-tuning script — loads the pretrained Transformer+TCNN backbone into the ISLSentenceReconformer (BiGRU→Transformer→TCNN) for word-level classification with curriculum FPS (1→50 fps, the source rate is NOT a cap). Loads the corpus through the canonical manifest and augments with the canonical set. Cosine with warm restarts + a plateau escape; the optimiser is EXTENDED (not recreated) at the unfreeze so the AdamW moments survive. Saves to `models/pretrained_phase_2_model/`.
- `phase3_trainer.py`: Phase 3 word-level fine-tuning from Phase-2 checkpoint. Replaces head for the new class count (the mismatching head is dropped by `utils/checkpoint_utils.py`), freezes the backbone for 5 epochs then unfreezes it with differential LR, curriculum FPS (the source rate is not a cap), augmentation after the split. Cosine with warm restarts + a plateau escape. Saves to `models/phase3_word_model/`.
- `phase4_trainer.py`: Phase 4 full-FPS fine-tuning from Phase-3 checkpoint. No frame clipping. Augmentation: random time-stretch, mirror, tilt, bounded shift (applied after the train/val split). 50 epochs: transformer frozen for the first 30 (CosineAnnealingWarmRestarts on RNN+CNN+head), then all layers train for the final 20 (CosineAnnealing) + a plateau escape. Saves to `models/phase4_word_model/`.
- `phase5_trainer.py`: Phase 5 maximum accuracy squeeze reusing the exact Phase 4 split (the canonical manifest, so it cannot go stale). All layers unfrozen, OneCycleLR with SWA. Saves to `models/phase5_word_model/`.
- `phase6_trainer.py`: Phase 6 high-precision squeeze trainer reusing the exact Phase 4/5 split. Lookahead wrapping decoupled AdamW, Annealed LR combined with ReduceLROnPlateau, Model EMA, SpecAugment temporal frame masking, and gentle mixup. Saves to `models/phase6_word_model/`.
- `pretrainer.py`: Transformer + Temporal CNN (TCNN) pretraining script training on MediaPipe pose sequences with median length normalization and geometric augmentations. Trains on the WORD corpus with a real file-level split (3135 train / 806 val clips, no overlap) — it used to load ONE clip per class and use it for both partitions, so its "98% validation accuracy" was memorisation. Cosine with warm restarts + a plateau escape.
- `structure.md`: Directory structure documentation for training.
- `train_conformer_ctc.py`: **Shared foundation for every CTC trainer.** ISL Conformer-CTC (MHA + Depthwise Conv, no global pooling) with a 4-stage curriculum (single-word, 2-word, N-word progressive, unfrozen polish). Also hosts the pieces reused by the real-sentence trainers: `AntiCollapseCTCLoss` (log-prob floor so "emit nothing" is not free + emission barrier + blank cap + spike penalty), `MaskedBatchNorm1d` (padding-aware BatchNorm), `harmonize_features()` (re-anchors the three differently-normalised corpora into one frame), `match_pretraining_domain()` (rewrites a clip into the isolated-word geometry the backbone was pretrained on), `escape_local_minimum()` (perturbation + BN reset + CTC-head rebalance + LR restart), and the augmentation set. The vocabulary is the published one and the Phase-6 word classifier is transferred INTO THE CTC HEAD BY CLASS NAME (the row order of the old checkpoint does not match anymore). `--stride` adds a strided convolution front-end (1/2/4) in front of the self-attention, `--gru_expand` chooses where the recurrent expansion happens (`before` = the Transformer receives the expanded tensors, `after` = the Conformer-CTC design), `--causal` makes the whole stack causal for streaming, `--layer_lrs` sets one learning rate per LAYER and `--freeze_transformer_epochs` / `--freeze_backbone_epochs` stage the release of the pretrained layers. `--beam_width` switches the evaluation to the prefix beam search, optionally rescored by the word-level language model (`--beam_alpha`). `--kd_weight` enables the **experimental** student-teacher consistency loss: it is OFF by default and NOT part of the recommended recipe, because the only teacher available is the Phase-6 word classifier (81.9% top-1, word-only, not trained properly) and a sentence model must not inherit its mistakes. **NOTE: the current version cannot train stage 1 (0% exact match, reproduced with both the HEAD and the f4ed0ce revision on 2026-10-20) — the saved `models/isl_conformer_ctc/stage{1,2,3}_*.pth` are good (67.2% / 57.8% exact match) and should be kept as the warm start.**
- `train_real_sentences.py`: Real continuous human sign sentence fine-tuner training Conformer-CTC on real continuous video streams with selective in-scope relabeling. Applies the cross-corpus feature harmonisation, the anti-collapse emission barrier, the padding-aware backbone, the blank-collapse watchdog, the local-minimum escape and an SWA tail checkpoint. The sentence targets are re-indexed onto the current vocabulary BY NAME. `--mix 1` draws the training set at random from three sources — isolated word clips (sign inventory), synthetic sentences (CTC alignment, padded with REAL continuous frames) and the real sentences (target domain). At startup it prints the **label prior of every source and of the mixture** (see `utils/word_distribution.py`): the two synthetic sources draw their classes uniformly, the continuous corpus is dominated by six pronouns, and the mixture lifts the effective support of the prior from ~36 to ~175 of the 228 classes. Both prior-correction knobs default to OFF on purpose, with the measurements: `--mix_word_cap 60` gives 87.2% WER (it DROPS ~40% of the only real data) and `--class_balance_alpha 0.5` gives 98.9% (fixing the prior in the loss breaks the CTC alignment) versus 75.0% with both off. `--max_out_scope 8` keeps 1296 real clips (the default 5 threw away 27% of them).
- `train_real_sentences_phase2.py`: Phase 2 continuous sentence fine-tuner incorporating CosineAnnealingWarmRestarts, SpecAugment temporal cutout, and a class-balanced focal CTC loss built on the shared anti-collapse loss. Saves to `models/isl_real_sentences_phase2/`.
- `train_real_final.py`: Master regularized continuous trainer warm-starting from Phase 2 real-sentence weights with the anti-collapse emission barrier, SpecAugment temporal cutout, zero-leakage prompt splits and the local-minimum escape. Saves to `models/isl_real_final/`.
- `train_reconformer_word.py`: Primary training script for ReConformer word-level models. Uses the shared word dataloader (top-most frequent classes, tier 14 / cap 20, `[NOTHING]` idle class) and the canonical augmentation set.
- `train_synthetic_sentences.py`: Phase 1 continuous sentence trainer using CTC loss. Generates synthetic sentences (1-10 words, no repetition, smooth co-articulation) from the selected word clips, and trains the CTC head over a frozen Phase 6 backbone. Uses the hardened `AntiCollapseCTCLoss` (the plain `nn.CTCLoss(zero_infinity=True)` it used before has the documented "emit nothing is free" exploit) and a local-minimum escape.
- `train_synthetic_sentences_phase2.py`: Phase 2+ unfrozen sentence trainer with dynamic phase auto-detection and cycling (automatically detects latest Phase K, initializes from its weights, and trains Phase K+1 into `islsentence_synthetic_phase{K+1}/`). Implements discriminative learning rates, Model EMA, Cosine Annealing, and regularized CTC loss.
- `train_weak_classes.py`: Implements class re-weighting and focused training on underrepresented sign classes.
