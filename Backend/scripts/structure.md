# scripts
- build_isign_dataset.py: Extracts word-level tensors from archive_extracted into tensors_include50_word_level/
- stable_extraction.py: Stable per-coordinate carry-forward extraction module
- visualize_tensor.py: Overlays extracted tensor stick figure on real video
- visualize_webcam.py: Real-time stick figure visualization on webcam feed
- generate_frequency_report.py: Generates combined word frequency report from all sources
- generate_two_source_freq.py: Generates two-source (isign + archive) word frequency CSV
