# Directory Structure: Backend/scripts/isign_pipeline

Dedicated data preparation and extraction pipeline for the iSign dataset.

## Files
- `extract_ab_hack.py`: Handles multi-part extraction and fixes for iSign dataset splits.
- `extract_tar_videos.py`: Decompresses tar archives of raw iSign video clips.
- `process_isign_videos.py`: Batch processes iSign videos and coordinates MediaPipe extraction.
- `structure.md`: Directory structure documentation for isign_pipeline.
