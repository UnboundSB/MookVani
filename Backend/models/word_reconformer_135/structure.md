# Directory Structure: Backend/models/word_reconformer_135

Model weights and evaluation artifacts for the 135-class isolated word ReConformer model.

## Files
- `classes_135.json`: Class index mapping for the 135-class isolated sign vocabulary.
- `reconformer_word_135_best.pth`: Checkpoint with the best validation accuracy during training.
- `reconformer_word_135_final.pth`: Final trained weights at completion of the training loop.
- `structure.md`: Directory structure documentation for word_reconformer_135.
- `word_135_confusion_matrix.png`: Confusion matrix plot for the 135-class model.
- `word_135_metrics.png`: Training and validation loss/accuracy curves.
