# Directory Structure: Backend/models/word_reconformer_229

Model weights and evaluation artifacts for the 229-class balanced word ReConformer model.

## Files
- `classes_balanced.json`: Class index mapping for the 229 balanced sign classes.
- `history_word.json`: Epoch-wise training loss, validation loss, and accuracy log.
- `reconformer_classification_report.txt`: Precision, recall, and F1 scores per sign class.
- `reconformer_confusion_matrix.png`: Confusion matrix visualization for 229 classes.
- `reconformer_metrics.png`: Training history curves.
- `reconformer_word_model.pth`: Trained model checkpoint for the 229-class model.
- `structure.md`: Directory structure documentation for word_reconformer_229.
