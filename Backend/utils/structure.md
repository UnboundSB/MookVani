# Directory Structure: Backend/utils

Shared utilities: the word-level and sentence-level dataloaders, the single
canonical implementation of the pose augmentations, the canonical train/val
manifest, the decoders, the checkpoint helpers, gloss normalization and the
evaluation metrics.

## The selection rule (used by every phase)
* **tier 14** - a class with fewer than 14 clips is ELIMINATED from the loader
  (its files stay on disk; the pretrainer and the other models still use them).
* **cap 20** - every surviving class contributes at most 20 clips.
* Result: **228 classes, 3941 clips**, a spread of 20/14 = 1.43x (the raw corpus
  spans 4..22 clips, i.e. 5.5x - the tier is what flattens it, the cap only
  adds data).
* The classes are ordered by descending clip count and the list is published in
  `models/word_vocabulary/classes.json`.

## Files
- `__init__.py`: Package entry point re-exporting the dataloaders, the augmentation primitives and the metrics helpers.
- `checkpoint_utils.py`: Checkpoint helpers that survive a change of the vocabulary. `load_flexible()` drops the shape-mismatched entries (the class heads) before loading, so a checkpoint trained on the old 262-class list can still warm-start the backbone of a model with the current class list instead of dying with a `RuntimeError: size mismatch`.
- `ctc_decoder.py`: CTC **prefix beam search** decoder with an optional word-level language-model rescoring (`score = log P_acoustic + alpha*log P_LM - beta*|words|`). Only the top-k labels of every frame are expanded, which keeps it ~50x faster than the exhaustive search. Used by the CTC evaluation and by the live recogniser.
- `dataloader_word.py`: **Word-level dataloader.** Loads the TOP-MOST FREQUENT classes of the word corpus (tier 14, cap 20, 228 classes / 3941 clips). Adds the synthetic `[NOTHING]` idle class (as the last label) and exposes the published vocabulary (`models/word_vocabulary/classes.json`). Also owns `FILL_MISSING_DEFAULT`, the single knob that decides whether a drop-out hole is filled with the last valid value or kept as a zero block, and `canonical_split_items()` / `load_word_split_tensors()`, the ONE entry point every phase uses to resolve the canonical split.
- `dataloader_sentence.py`: **Sentence-level dataloader.** Loads the continuous sentence tensors (via `index.json`, re-indexed onto the current vocabulary BY NAME) AND the word clips the word model was trained on, and applies the canonical augmentation set (mirror / tilt / bounded left-right shift / speed up or slow down / temporal shift / SpecAugment) plus the temporal hole filling.
- `distillation.py`: **EXPERIMENTAL, and deliberately NOT part of the recommended recipe.** `WordTeacher` is a frozen word model (the Phase-6 classifier) whose head rows are re-mapped BY CLASS NAME onto the current vocabulary; `batch_distillation_loss` compares the teacher's belief about an isolated word with the student's belief inside the frames that word occupies in the stitched sentence. A word is only used when the teacher AGREES with the ground truth and is confident enough: that is the filter that removes the ambiguous (noisy) words from the training signal. **The only teacher available today is word-only, 81.9% top-1 and not trained properly, so a sentence model must not inherit its mistakes — keep `--kd_weight 0` until a proper sentence-level teacher exists (e.g. the YAP segmentor with its word boundaries).**
- `gloss_utils.py`: Tokenization, text normalization, and gloss-to-index mapping utilities.
- `plotting.py`: **The plotting utilities of the project** - one implementation for every model family (the word classifier, the CTC sentence model, the segmentor). `plot_training_curves` draws the loss, the accuracy (with the chance level), the F1/precision/recall, the WER/exact-match and the learning rate of every parameter group; `plot_confusion_matrix` draws **the confusion matrix** (row-normalised = the per-class recall, restricted to the N most confused classes so it stays readable) and writes a TEXT report next to it (the per-class precision/recall/F1 and the 20 worst confusions - a 228x228 picture is not readable); `plot_per_class_metrics` draws the per-class bars sorted worst-first; `plot_label_distribution` draws the label prior of a corpus; `write_report` produces the whole set plus a summary. It understands BOTH history conventions (the short keys of the word phases and the long ones of the sentence trainers).
- `pose_augmentation.py`: **The single source of truth for the pose augmentations.** Canonical 163-dim layout, the missing-modality convention (an undetected modality owns a zero block), the cross-corpus geometric harmonisation, and the augmentation primitives: `mirror_pose` (every left/right pair swapped, mouth corners included, around the signer's own axis), `tilt_pose` (around the neck), `shift_pose` (bounded left/right shift), `time_stretch` (speed up / slow down), `temporal_shift`, `temporal_mask`, `scale_pose`, plus `fill_missing_temporal` / `TemporalPoseTracker` (carry the last valid value forward instead of dropping a landmark to zero). It also holds the layout adapters of the segmentor: `pose_to_canonical` / `canonical_to_pose` move between the 163-dim tensor and the 53-joint corpus pose (the two hands + the 2 shoulders + the 2 elbows + the 7 face points) that `YAPConfig.corpus()` expects, and `augment_hands_batch` applies the canonical augmentation to a padded batch (restoring the length, because the temporal augmentations change it).
- `splits.py`: **The canonical train/val manifest** (`models/word_vocabulary/split.json`). It pins, for every class, the exact training clips and the exact validation clips, so a clip that is training data in one phase is never validation data in another. `audit_split()` checks the three ways a split can leak, and `split_fingerprint()` makes a mismatch detectable instead of silent.
- `structure.md`: Directory structure documentation for utils.
- `training_utils.py`: Training helpers shared by the word and the sentence trainers: `unfreeze_and_extend` (releases a frozen part of the model WITHOUT throwing away the AdamW state), `escape_from_plateau` (perturbation + BatchNorm reset + LR reset), the warm-restart / warmup schedulers, `build_layer_param_groups` (one learning rate per LAYER: the new modules learn fast, the pretrained ones slowly), `PerGroupCosineAnnealing` (every layer group is annealed to `base_lr * min_lr_ratio`, because a single `eta_min` would push the pretrained layers to zero) and `freeze_layers` (the staged freeze / release schedule).
- `word_distribution.py`: **Label-prior diagnostics.** Measures the word-frequency distribution of every training source (the isolated word clips are flat, the continuous corpus is dominated by six pronouns) and of their mixture, and reports the *effective support* (exp of the entropy): the number of classes the model effectively sees. It is what makes the choice of a frequency cap a decision taken on numbers instead of on intuition.
- `word_lm.py`: A smoothed unigram + bigram **word-level language model** for the decoders, built from the TRAINING split of the continuous corpus (the validation sentences stay unseen, so the tuning of the LM weight stays honest). The decoder uses the **bigram only** (the word order): the unigram prior of the continuous corpus is the pronoun skew that causes the collapse.
